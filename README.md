# Oblivion IDE Studio

The free Windows IDE for AI coding agents: Claude Code and Grok in up to four terminals,
right beside a live preview of the app they're building, with phone and tablet frames built in.

**[Download for Windows](https://github.com/DevPodo/oblivion-releases/releases/latest/download/Oblivion-IDE-Studio-Setup.exe)** · [Website](https://www.oblivionide.com) · [Docs](https://docs.oblivionide.com)

## Install

1. Download `Oblivion-IDE-Studio-Setup.exe` from the [latest release](https://github.com/DevPodo/oblivion-releases/releases/latest).
2. Run it. If Windows says it protected your PC, click **More info**, then **Run anyway**
   (the installer isn't code-signed yet).
3. Sign in with Google and open your project folder.

You need Windows 10 or 11 (64-bit) and Claude Code or the Grok CLI, signed in with your own account.

Oblivion updates itself: new versions download in the background and install when you click
**Restart to update** or close the app.

This repository only holds the installers. Questions and bug reports go in
[Issues](https://github.com/DevPodo/oblivion-releases/issues).
